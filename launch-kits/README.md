# 簡易導入キット

テーマの長い説明、最小範囲、比較軸、評価指標候補は公開教材の個別テーマページを正本とします。このディレクトリには、開始時に必要な共通ガイドと、検証済みの小さな実行資産だけを置きます。

## 配布するもの

- 12テーマと経路を対応づける `catalog.toml`
- [自作ソルバ型](build-a-solver/README.md)、[自分のソルバ再利用型](reuse-your-solver/README.md)、[公開パッケージ型](guided-package/README.md)、[自由提案型](open-proposal/README.md)の開始ガイド
- テーマ検証が完了したテーマだけに追加する、参照データ、縮小入力、補助スクリプト、可視化、または固定パッケージの例

## 学生が決めること

問い、比較条件、評価指標、ソルバ構成と内部API、実験、図表、結果の解釈はプロジェクトごとに決めます。

## テーマパックの使い方

1. 公開教材の個別テーマページで現象、最小範囲、二層検証を確認する。
2. `catalog.toml`で経路と、公開済みの場合だけ記録される資産・簡易な事前診断を確認する。
3. 経路別ガイドを読み、配布資産を自分のプロジェクトへどう取り込んだか記録する。
4. 自分の問い、比較、追加検証を設計し、小さなCPUケースから始める。

## 配布元と利用条件

このディレクトリは公開教材の任意の参考資産です。必要なファイルだけを自分で作成したプロジェクトへ取り込み、教材のURL、参照元commit、変更点を記録してください。
