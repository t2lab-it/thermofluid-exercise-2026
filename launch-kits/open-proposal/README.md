# 自由提案型

このガイドは穴埋め式の完成ソルバではありません。

自由提案にはテーマ固有のスターターやテーマパックを用意しません。次を計画フィードバックの材料としてまとめ、実現方法と代替案を教員・TAと具体化します。

- 問いと、熱流体または空間場を扱う理由
- 既存12テーマ・3経路との違い
- 2条件以上の比較と事前評価指標
- 局所的な数値契約と現象・参照値による二層検証
- 縮小ケース、代表計算の時間・メモリ・必要資源の見積もり
- パッケージ、データ、ライセンス、公開・非公開の境界
- 計画どおり成立しない場合の代替案

フィードバックは審査・選抜ではなく、成立する範囲と検証経路を一緒に作るために使います。問い、ソルバ構成、実験、図表、解釈は学生が決めます。
