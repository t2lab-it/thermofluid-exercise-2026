# 自作ソルバ型

このガイドは穴埋め式の完成ソルバではありません。

## 配布資産の範囲

公開テーマページの問題設定、参照データまたは解析・ベンチマークへの入口、教員が確認した縮小ケース、必要最小限の入力・補助・可視化資産を利用します。事前診断は環境、データ、補助スクリプト、入力、可視化を確認するもので、学生のソルバを代わりに解きません。

## プロジェクトで決めること

- ソルバ構成、関数名、内部API、ファイル構成
- 問いと2条件以上の比較
- 評価指標、離散化・時間積分・停止条件
- 数値契約、縮小ケース、本実験、図表、解釈

参照値へ合うことだけを目的にせず、まず局所的な数値契約を作り、次に現象・ベンチマークで検証する二層構成にします。
