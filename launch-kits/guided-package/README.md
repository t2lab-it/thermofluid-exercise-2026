# 公開パッケージ型

このガイドは穴埋め式の完成ソルバではありません。

この経路だけは、テーマ検証で固定したパッケージ版の公式例または教員が固定した派生例を再現できる状態から始めます。固定版、上流URL・パス・ライセンス、授業側の変更はテーマパックに記録します。

## プロジェクトで行うこと

1. 固定例を再現し、方程式、境界・初期条件、主要パラメータ、診断量を説明する。
2. 一度に一つの意味のある条件を変え、問いと比較を自分で設計する。
3. 数値契約と、解析解・ベンチマーク・保存量・格子依存性などの現象側検証を組み合わせる。
4. パッケージが保証する範囲、設定依存性、既知の失敗、適用限界を区別して解釈する。

公式例の再実行だけ、設定値の変更だけ、パッケージ出力の完成図だけではプロジェクトの結論になりません。
