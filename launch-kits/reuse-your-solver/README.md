# 自分のソルバ再利用型

このガイドは穴埋め式の完成ソルバではありません。

ソルバ本体は配布しません。N09までの自分のソルバなど、出典と参照元commitを記録できるコードをプロジェクトへ持ち込みます。

## 比較前に固定するもの

- 参照元リポジトリまたは参照元と参照元commit
- 正しさを確認済みの比較基準と数値契約
- 入力、問題規模、処理量、スレッド・デバイス条件
- 事前実行、測定回数、時間・メモリ・割当て量の集計方法
- 比較基準と変更後の場を比較する回帰検証

問い、変更箇所、ソルバの呼出し方、性能指標、比較条件はプロジェクトが決めます。高速化率や前処理効果が出なかった場合も、同じ処理量で正しさを保ち、測定と原因を説明できれば検討対象になります。
