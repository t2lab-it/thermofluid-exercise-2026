# 湿潤床ダム崩壊の参照資産

この小規模パックは、水平・摩擦なしの一次元浅水方程式に対するStokerの湿潤床ダム崩壊解から作った小さな参照表と、その読込み・正の水深・波の順序だけを確認するCPU向け事前診断を提供します。

## 固定する縮小ケース

| 量 | 値 |
|---|---:|
| 重力加速度 | \(g=9.81\ \mathrm{m\,s^{-2}}\) |
| 領域 | \(-5\le x\le5\ \mathrm{m}\) |
| ダム位置 | \(x_0=0\ \mathrm{m}\) |
| 上流水深 | \(h_L=1.0\ \mathrm{m}\) |
| 下流水深 | \(h_R=0.1\ \mathrm{m}\) |
| 初期流速 | \(u_L=u_R=0\ \mathrm{m\,s^{-1}}\) |
| 参照時刻 | \(t=0.5\ \mathrm{s}\) |

初期水深比は \(h_L/h_R=10\) です。下流深さが正の湿潤床ケースであり、乾燥床はこのパックの対象外です。この時刻では左向き希薄波、中間状態、右向き衝撃波はいずれも境界へ到達しません。

浅水方程式は

\[
h_t+(hu)_x=0,
\qquad
(hu)_t+\left(hu^2+\frac12gh^2\right)_x=0
\]

です。Stoker解の中間水深 \(h_m\) は

\[
2(\sqrt{gh_L}-\sqrt{gh_m})
=(h_m-h_R)\sqrt{\frac{g(h_m+h_R)}{2h_mh_R}}
\]

を満たし、このケースでは
\(h_m=0.3961748167994429\ \mathrm{m}\)、
\(u_m=2.3213549956407444\ \mathrm{m\,s^{-1}}\) です。波の速度は希薄波先端 \(-3.132091952673165\ \mathrm{m\,s^{-1}}\)、後端 \(0.34994054078795145\ \mathrm{m\,s^{-1}}\)、衝撃波 \(3.1051336506682135\ \mathrm{m\,s^{-1}}\) の順です。

## ファイル

- `stoker-reference.csv`: \(t=0.5\ \mathrm{s}\) における位置、水深、流速
- `preflight.jl`: CSV列、有限値、正の水深、左状態 → 希薄波 → 中間状態 → 右状態の順序を確認

実行:

```bash
julia --startup-file=no preflight.jl
```

事前診断は参照表の水深と波の順序を確認し、結果を端末に表示します。
